# 3D Mascot Model

Place your GLB model file here:

**File name:** `mascot.glb`

**Requirements:**
- Format: GLB (binary glTF)
- Should include animations (idle animation recommended)
- Optimized for web (keep file size reasonable)
- Kid-friendly, cute character design

**How to create:**
- Export from Blender, Maya, or other 3D software
- Use glTF exporter
- Optimize with gltf-pipeline if needed

**If model doesn't exist:**
- The app will show a loading fallback
- Add your `mascot.glb` file to this folder
- The 3D mascot will automatically appear
