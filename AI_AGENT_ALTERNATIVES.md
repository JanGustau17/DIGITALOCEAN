## 📝 Setup Instructions

### Option 1: OpenAI GPT-4 (Recommended)

1. **Get API Key**: https://platform.openai.com/api-keys
2. **Add to `.env.local`**:
   ```env
   OPENAI_API_KEY=sk-your-key-here
   AI_PROVIDER=openai
   ```

3. **Cost**: ~$0.01-0.03 per activity (very affordable)

### Option 2: Anthropic Claude

1. **Get API Key**: https://console.anthropic.com/
2. **Add to `.env.local`**:
   ```env
   ANTHROPIC_API_KEY=sk-ant-your-key-here
   AI_PROVIDER=anthropic
   ```

### Option 3: Enhanced GradientAI

Just improve the prompts (no new API needed)

## 🔄 How It Will Work Differently

### Example Scenarios:

**Scenario 1: Kid chooses "stormy" + "stuck" + intensity 85**
- **Old**: Generic breathing exercise
- **New**: "I can see you're feeling really stormy and stuck right now. That's okay - big feelings happen! Let's try something that helps when everything feels too much..."

**Scenario 2: Kid chooses "excited" + "buzzy" + "friends"**
- **Old**: Generic focus activity
- **New**: "Wow, it sounds like you're super excited about your friends! That's awesome! Sometimes when we're this buzzy, our body needs a little help calming down. Let's try..."

**Scenario 3: Kid chooses "tired" + "heavy" + "school"**
- **Old**: Generic movement
- **New**: "School can feel really heavy sometimes, especially when you're tired. I get it. Let's do something gentle that helps your body feel lighter..."
